# 🌟 星露谷模组检查器 (Stardew Valley Mod Checker) v3.0

一款基于**真实 SMAPI 引擎**的星露谷物语模组健康度检测工具。  
告别传统不稳定的日志行号匹配，本工具通过反射加载 SMAPI.Toolkit，提供精准、全面的模组冲突与缺失检测，并一键生成美观、易读的 HTML 诊断报告。

> **当前版本**: v3.0 (2026-06-10) | **.NET**: 8.0 | **状态**: 稳定发布

---

## ✨ 核心特性

- **真实 SMAPI 引擎解析**：反射加载 `JsonHelper.Deserialize<T>()`，Manifest 解析逻辑与 SMAPI 官方完全一致，准确率 100%。
- **22+ 维度深度检测**：涵盖 UniqueID 冲突、依赖图断裂、缺失 EntryDll、ContentPackFor 有效性验证及 XNB 替换检测等。
- **单文件 HTML 报告**：替代旧版分散的 4 个文件，采用 4 Tab 设计（问题明细 / 报错导出 / 模组摘要 / 模组总览表），支持默认折叠与实时搜索，告别满屏红字焦虑。
- **极致便捷的操作**：支持将 exe 放入 `Mods` 目录双击运行，或直接**拖拽**任意 Mods 文件夹到 exe 上。扫描完成后自动唤起浏览器。
- **三格式一键导出**：支持完整报错日志 (TXT)、简化版+AI 提示词 (TXT)、开发者 Markdown 报告，方便直接发给作者或 AI 助手求助。

## 🚀 快速开始

### 1. 获取工具
下载最新发布的 `V3.exe`（约 65MB）。  
*注：本程序为 .NET 8.0 自包含单文件发布，**无需**在电脑上预先安装 .NET 运行环境。*

### 2. 运行方式（任选其一）
- **方式 A（推荐）**：将 `V3.exe` 直接放入你的星露谷物语 `Mods` 文件夹中，双击运行。
- **方式 B（拖拽）**：直接鼠标左键按住你的 `Mods` 文件夹，拖拽到 `V3.exe` 图标上释放。

### 3. 查看报告
扫描完成后，程序会自动在你的默认浏览器中打开生成的 HTML 报告。同时控制台会保持 UTF-8 编码输出，确保中文显示不乱码。

## 📖 报告使用说明

生成的 HTML 报告包含四个核心标签页：
1. **问题明细**：按严重程度分类展示检测到的问题，默认折叠，支持关键词实时搜索过滤。
2. **报错导出**：提供三种格式的复制与下载按钮（完整日志 / AI 辅助诊断格式 / 开发者 MD 格式），文件名自动附带日期（如 `mod_checker_log_20260610.txt`）。
3. **模组摘要**：快速统计当前 Mods 文件夹中的模组总数、异常数量及 SMAPI/游戏版本信息。
4. **模组总览表**：以表格形式列出所有被扫描模组的 UniqueID、名称、版本及状态。

## 🔍 检测能力清单 (v3.0)

| 检测维度 | 说明 |
| :--- | :--- |
| **UniqueID 冲突** | 全库哈希比对，发现重复 ID 直接报错 |
| **依赖图检测** | 遍历 Dependencies，标记缺失依赖和 ContentPackFor 链断裂 |
| **EntryDll 验证** | 校验 Manifest 中声明的 DLL 文件是否在物理目录中真实存在 |
| **ContentPackFor** | 检查引用的框架模组（如 Content Patcher）是否实际安装并启用 |
| **XNB 替换检测** | 扫描模组目录中是否存在直接替换原版资产的 `.xnb` 文件（基础版） |
| **版本读取** | 直接读取 DLL/EXE 文件的 FileVersion，精准获取 SMAPI/游戏版本，不依赖日志 |
